# Assembly Guide

Apply solder paste via stencil, place SMT components, and reflow. Place and solder remaining THT components except LEDs.

With the face plate temporarily installed, position and solder the red and green level LEDs (D1, D2, D4, D5). The LEDs should protrude slightly through the openings in the face plate.
